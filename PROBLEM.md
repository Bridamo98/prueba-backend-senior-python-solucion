¿En qué consiste?

Deberás construir un servicio HTTP en Python (FastAPI + SQLAlchemy) que evalúe solicitudes de crédito aplicando distintas políticas de aprobación según el tipo de producto (PHONE, TWIST, CARD). El enunciado completo, las reglas de negocio, los endpoints requeridos y la estructura sugerida están documentados en el README del repositorio.

El tiempo estimado es de 1 hora. Solo necesitas tener Docker Desktop instalado; el entorno de ejecución y los tests ya están configurados.

---
Consideraciones importantes

- Supuestos: El enunciado no cubre todos los escenarios posibles deliberadamente. Eres libre de asumir lo que consideres razonable; lo importante es que documentes tus decisiones (en el README, en comentarios de código, o en el mensaje del PR/commit). No hay una única respuesta correcta.

- Servicios externos o dependencias no entregadas: Si en tu solución necesitas integrar o simular un servicio externo que no está provisto (por ejemplo, un sistema de scoring, notificaciones, etc.), puedes mockearlo, simularlo con datos fijos o abstraerlo detrás de una interfaz. Lo que evaluamos es el diseño de tu solución, no la integración real.

- Preguntas: Si tienes alguna duda sobre el enunciado, los requisitos o el contexto de negocio, escríbeme directamente a este correo. Responderé a la brevedad.
